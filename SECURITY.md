# Sicherheit

## Unterstützte Versionen

Sicherheitskorrekturen gibt es ausschließlich für die neueste stabile Minor-Linie —
derzeit als Beispiel die Linie `2.14.x`; die Regel gilt, nicht diese Nummer.

Meldungen werden zu allen Patchständen dieser Linie angenommen. Eine Korrektur
erscheint als neuer Patchstand dieser Linie; auf ältere Patchstände wird nicht
zurückportiert. Ältere Minor-Linien erhalten keine Sicherheitskorrekturen.

## Eine Schwachstelle melden

Bitte melde eine Schwachstelle **vertraulich** per Mail an <info@mwolff.org>.
Wer ein GitHub-Konto hat, kann alternativ GitHub Private Vulnerability Reporting
nutzen: im Repository über den Reiter „Security“ → „Report a vulnerability“.

**Mache eine Schwachstelle nicht als öffentliches Issue auf.** Die Mail steht
hier zuerst, weil sie ohne GitHub-Konto funktioniert.

## Was du erwarten darfst

Der Maintainer bestätigt den Eingang deiner Meldung binnen fünf Werktagen.

Eine Frist für die Korrektur wird **nicht** zugesagt: Dies ist ein Nebenprojekt,
und eine Zusage, die daran scheitert, wäre weniger wert als keine.
